Issues can be used to help identify a bugs in a codebase, along with how they can be reproduced and some suggestions for how to fix them. Branches can be used to test out fixes to issues that have been reported without affecting the working branch of the repository. Commits are used to apply changes to a particular branch in order to apply changes to known issues in order to see whether or not the issue has been resolved. Pull requests can be used to directly propose the exact modifications required in order to fix issues, along with feature suggestions as well. The default branch is the primary working branch of a repository where fixes to known issues are applied after being tested on a separate branch. It should always be the most stable branch and no experimentation with new features or bug fixes should occur here directly.
